HOT N JUICY SHRIMP LDN — STATIC WEBSITE CONCEPT

Files:
- index.html   Main one-page website
- styles.css   Responsive design and styling
- script.js    Small mobile navigation interaction

HOW TO PREVIEW:
1. Extract the ZIP file.
2. Open index.html in a modern web browser.

HOW TO PUBLISH:
- Upload all three files to the public_html folder in your IONOS web hosting space.
- Keep the file names and folder structure unchanged.
- The website is static: it has no database, server-side code, shopping cart backend or booking engine.

IMPORTANT:
- Food photography is loaded from the existing Hot N Juicy Shrimp LDN website, so an internet connection is required to display those images.
- Order, booking, menu, catering and shop buttons link to the existing restaurant website. They do not process orders on this static site.
- Location details, hours, shop price and testimonials were transcribed from the original public website and should be checked by the business before launch.
- This is an independent redesign concept, not an export of the original Shopify theme or its source code.
- Replace the email link in the footer if the business uses a different customer service address.
